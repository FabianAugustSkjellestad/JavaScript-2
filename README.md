# JavaScript 2
Course assignment in JavaScript 2 - Social media app

# Description
This is Connect. A social media app built with front-end as part of JavaScript 2 course at Noroff
The application interacts with the Noroff Social API and allows users to register, log in, and perform CRUD (Create, Read, Update, Delete) operations on posts. Users can also follow/unfollow other users, search posts and view profiles.

# Built with
* HTML
* Vanilla JavaScript (ES6 Modules)
* CSS
* Noroff Social API

# Installation
Follow the steps to run the project locally:
* Clone the repository
  https://github.com/FabianAugustSkjellestad/JavaScript-2.git
* Open the project on VS Code
* Start the project using live server

# Usage
When running the project:
- Register or log in (@stud.noroff.no)
- View posts
- Post own posts
- Follow/unfollow others
- Edit your own posts
- Delete posts
